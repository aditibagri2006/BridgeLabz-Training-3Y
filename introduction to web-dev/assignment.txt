1. Frontend, Backend, and Full-Stack Development

Frontend Development:
Frontend is the part of a website or web application that users can see and interact with. It includes the layout, buttons, forms, images, navigation menus, colors, and animations.

Common technologies:

HTML – structure of the webpage
CSS – styling and design
JavaScript – interaction and functionality
Frameworks such as React, Angular, and Vue.js

Example: On Amazon, the product page, search bar, "Add to Cart" button, images, and menus are part of the frontend.

Backend Development:
Backend is the server-side part of a web application. It processes requests, performs business logic, handles authentication, communicates with databases, and sends data to the frontend.

Common technologies include Node.js, Python/Flask/Django, Java/Spring Boot, PHP, and databases such as MySQL and PostgreSQL.

Example: When a user logs into Amazon, the backend verifies the username/password, retrieves account information from the database, and sends the required information back to the frontend.

Full-Stack Development:
Full-stack development involves working on both frontend and backend.

Example: A full-stack developer building an e-commerce website may create the product pages using React and also develop APIs and database connections using Node.js and PostgreSQL.

3. How a Browser Requests and Displays a Web Page

When a user enters a URL such as https://www.example.com, the following process occurs:

URL entered: The user enters the website address in the browser.
DNS lookup: The browser uses DNS to find the IP address associated with the domain.
Connection: The browser establishes a connection with the web server, normally using HTTPS.
HTTP request: The browser sends an HTTP request such as GET /.
Server processing: The web server receives and processes the request.
HTTP response: The server sends HTML and other required resources back to the browser.
HTML parsing: The browser reads the HTML and creates the page structure.
CSS processing: CSS is applied to determine the appearance and layout.
JavaScript execution: JavaScript adds functionality and interactivity.
Rendering: The browser renders the final webpage on the screen.

So, the basic process is:

URL → DNS → Server Request → Server Response → HTML/CSS/JS → Browser Rendering

5. Web Server

A web server is software or hardware that receives HTTP/HTTPS requests from clients and provides web pages, files, or data in response.

For example, when a user requests:

https://example.com/index.html

the web server receives the request, locates or generates the required content, and sends an HTTP response to the browser.

Common web servers include:

Apache HTTP Server – popular open-source web server.
Nginx – high-performance web server also commonly used as a reverse proxy.
Microsoft IIS – Microsoft's web server for Windows environments.
LiteSpeed – performance-oriented web server.
Caddy – modern web server with convenient automatic HTTPS support.
6. Roles in a Web Development Project

Frontend Developer:
A frontend developer creates the user-facing part of the application.

Responsibilities include:

Creating webpage layouts
Developing responsive interfaces
Working with HTML, CSS, and JavaScript
Connecting frontend applications with APIs
Improving usability and user experience

Backend Developer:
A backend developer creates the server-side functionality of an application.

Responsibilities include:

Developing APIs
Implementing business logic
Authentication and authorization
Communicating with databases
Handling client requests
Implementing application security

Database Administrator (DBA):
A DBA manages the application's databases.

Responsibilities include:

Creating and maintaining databases
Managing database users and permissions
Monitoring performance
Creating backups
Restoring data when required
Maintaining database security and availability

9. Five Web Browsers and Their Rendering Engines

A rendering engine converts HTML and CSS into the visual webpage displayed on the screen.

Browser	Rendering Engine
Google Chrome	Blink
Microsoft Edge	Blink
Mozilla Firefox	Gecko
Apple Safari	WebKit
Opera	Blink

Blink:
Used by Chromium-based browsers such as Chrome, Edge, and Opera. It is derived from WebKit and is developed as part of the Chromium ecosystem.

Gecko:
Developed by Mozilla and used by Firefox. It has its own implementation for processing and rendering web content.

WebKit:
Used by Safari. Blink was originally forked from WebKit, but the two engines have evolved independently.

Although modern browsers generally follow web standards, differences in their rendering engines can sometimes cause small differences in CSS behavior, supported features, performance, fonts, and page rendering. Therefore, developers commonly test websites on multiple browsers.
