Responsive Design

Responsive design allows websites to automatically adjust their layout according to the size of the user's screen.

Flexbox, Grid, media queries and flexible units are commonly used to create responsive websites.

Cheat Sheet

Flexbox → Flexible alignment

Grid → Two-dimensional layout

Media Query → Responsive breakpoints

Clamp → Flexible typography
